# מתופף וירטואלי

אפליקציית רשת (PWA) לאייפון: בוחרים שיר או וידאו מהטלפון, ומערכת תופים מונפשת מנגנת יחד עם השיר. רואים איזה תוף מקבל מכה, באיזו יד, ומתי.

## איך זה עובד
1. **הפרדת תופים** (`separator-worker.js`): מודל AI בשם Open-Unmix (רישיון MIT) רץ בתוך הטלפון ומפריד את התופים משאר השיר. בפעם הראשונה המודל נטען (35MB). כל שיר שהופרד נשמר במכשיר, ולכן פתיחה חוזרת שלו מהירה.
2. **זיהוי מכות** (worker בתוך `index.html`): זיהוי זמני ההתחלה של המכות (STFT, הפרדת רכיבים הרמוניים ממקצביים, ספי זיהוי מסתגלים, חזרה לתחילת המכה), סיווג לסוגי תופים לפי תדר ולפי משך הצלצול, וזיהוי קצב. בס, סנר והיי-האט מזוהים מתוך ערוץ התופים המופרד. טומים ומצילות מזוהים מתוך השיר המלא.
3. **הנפשה** (`app.js`): המכות מסונכרנות לשעון השמע, עם פיצוי על השהיית הפלט ועל השהיית המסך. יש כיול בהקשות לאוזניות בלוטות'.

## מצבי שמיעה
שיר מלא / רק תופים / בלי תופים. במצב "בלי תופים" אפשר לתופף בעצמך במקום המתופף.

## בדיקות
`test/compare.js` משווה את הזיהוי לשירי בדיקה סינתטיים שזמני המכות בהם ידועים, עם הפרדת תופים ובלעדיה. ליצירת שירי הבדיקה: `node -e "require('./test/synth.js')"`. פרטים נוספים ב-`test/synth.js`.
